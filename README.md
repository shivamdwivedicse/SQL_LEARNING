## 📖 About

This repository is my personal SQL learning log. Each file represents a concept or practice session as I build strong database skills for **Data Analytics**, **Data Science**, and **ML Engineering** roles.

## 🧠 Concepts Covered

- ✅ **DDL** — CREATE, ALTER, DROP, TRUNCATE
- ✅ **DML** — INSERT, UPDATE, DELETE
- ✅ **DQL** — SELECT with filtering, sorting, grouping
- ✅ **Data Types** — Integer, character, boolean, date/time
- ✅ **Constraints** — PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK, DEFAULT
- ✅ **Clauses** — WHERE, GROUP BY, HAVING, ORDER BY, LIMIT, OFFSET
- ✅ **Operators** — Arithmetic, comparison, logical, pattern matching
- ✅ **Aggregate Functions** — COUNT, SUM, AVG, MIN, MAX
- ✅ **String Functions** — UPPER, LOWER, TRIM, LENGTH, SUBSTRING, CONCAT
- ✅ **Table Relationships** — One-to-many, foreign keys
- ✅ **Joins** — INNER, LEFT, RIGHT, FULL OUTER
- 🔜 **Subqueries & CTEs**
- 🔜 **Window Functions**
- 🔜 **Indexes & Performance**
